# Allergy Nutrition Platform

## Overview

Allergy Nutrition Platform is a web application developed using ASP.NET Core MVC to help users manage food allergies and make safer nutritional choices.

The platform allows users to:

- Manage personal allergies
- Check food products and allergens
- Discover restaurants
- Browse allergy-friendly recipes
- Save favorite products
- View personalized product safety status

---

## Features

### User Management
- User registration
- User login and logout

### Product Management
- Create, edit, delete, and view products
- Search products by name, brand, or category
- Personalized safety status based on user allergies

### Allergy Management
- Predefined allergy categories
- Personal allergy profile management

### Restaurant Management
- Create, edit, delete, and view restaurants

### Recipe Management
- Create, edit, delete, and view allergy-friendly recipes

### Favorites
- Save and manage favorite products
